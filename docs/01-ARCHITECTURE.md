## Потоки данных

### 1. Telegram ↔ Бот
```
Пользователь → Telegram API → (VLESS прокси) → 3dprinter_bot
3dprinter_bot → (VLESS прокси) → Telegram API → Пользователь
```
Причина прокси: провайдер atlas (Ростелеком) режет `api.telegram.org` — без прокси у aiogram постоянные `ServerDisconnectedError`.

### 2. Бот → Принтеры (Moonraker API)
```
3dprinter_bot → (NO_PROXY, напрямую) → wg0 → Routerich → LAN → Принтер
```
Трафик к `192.168.10.x` исключён из проксирования через `NO_PROXY`. Идёт напрямую через WireGuard-интерфейс сервера.

### 3. Бот → Gemini AI
```
3dprinter_bot → HTTP_PROXY=http://proxy:1080 → sing-box → VLESS Reality → Италия → Google AI
```
Gemini API заблокирован для российских IP. Обходим через VLESS Reality прокси в Италии.

### 4. Пользователь → Fluidd Web UI
```
Браузер (с VPN) → printer.example.com → Caddy (IP allowlist) → Fluidd SPA + /pN/* → Moonraker
```
Доступ только из LAN/VPN. Без VPN — `403 Forbidden`.

## Принцип разделения ответственности

| Компонент | Зона ответственности |
|-----------|---------------------|
| **Telegram-бот** | Мониторинг статусов, управление печатью, загрузка G-code, AI-чат, фоновые алерты |
| **Fluidd Web UI** | Полный доступ к Klipper: оси, конфиги, камеры, температурные графики |
| **Caddy** | TLS-терминация, reverse proxy, IP-based access control |
| **WireGuard** | Шифрованный туннель между atlas и домашней сетью принтеров |
| **sing-box (VLESS)** | Обход геоблоков для Gemini API и Telegram API |
